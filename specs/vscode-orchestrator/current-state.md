## What holds today

- Agent Manager is the only chat surface in the product. The older single-chat
  sidebar and editor-tab chat are gone from the tree.
- One extension-owned private `bin/kilo-serve serve --port 0` child outside the extension host is the sole operational owner: `ServerManager`-owned single process holds the same `AppLayer`, session SQLite, data-root lease, and operational facts. Internal HTTP/SSE through the generated SDK remains inside that private process as the current session authority, not a future contract.
