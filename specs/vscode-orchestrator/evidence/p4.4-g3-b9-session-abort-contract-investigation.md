## Lifecycle matrix (current tree vs contract)

| Case | Current-tree behavior | Contract requirement (B9-LOCK) |
|---|---|---|
| success | `cancelTree` interrupts intakes/runners/jobs, returns volatile `true`; no per-target disposition | Aggregate actually-interrupted generations + queued work + descendants + event publication into one terminal outcome |
| already terminal (session cancellation scope) | Missing runner → set `idle`, return `true`; indistinguishable from real cancel | Idempotent no-op returning the existing terminal outcome, not fresh `true` |
| missing session | No `requireSession` in abort handler; cancel proceeds on unknown id | `session.not_found`-class typed failure with scope binding, no side effect |
| timeout | No timeout/typed outcome defined; the static investigation does not prove the exact caller-visible symptom | Typed timeout outcome per B9-LOCK-005; never mutates stream/session state |
| cancel miss (busy race) | `assertNotBusy`/`RunnerBusy` path is prompt-side; abort reports `true` regardless | Outcome reports the missed generation as not-affected, not success |
| epoch drift | No epoch check in abort path | Stale-epoch request fails closed without state change |
| descriptor close | No descriptor/lease concept in abort path | Closed-descriptor request fails closed without state change |
| peer replacement | Client fans out to all known dirs; replacement backend gets a fresh abort, not identity-bound | Cancellation-request identity binds one backend epoch; replacement needs a new request identity |
| private transport unknown | No private abort path today, so nothing to misreport | When a carrier exists: warn-only detached observation per B9-LOCK-002/B9-LOCK-004/B9-LOCK-005 |
