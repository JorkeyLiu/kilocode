## Darwin Extension Host proof boundary

| Boundary | What is proven | How |
|---|---|---|
| Shared backend identity | Agent Manager + editor-tab `openInTab` share same `pid/port/epoch`/`kilo-private/1` + `session/update` | `requestPrivateStatus` before/after `requestOpenTab` |
| SDK authoritative | `PATCH /session/:id` `sessionUpdate:<id>:<token>` → `succeeded` with `revision` | `fixtureSessionUpdate` SDK then private |
| Private replay-only | same `opId`/`idempotencyKey`/`requestId` replays same `revision` without new mutation | `fixturePrivateReplay` pre- and post-restart |
| SSE epoch | `SseReconnect` keeps same `pid/port/epoch`, ≥1 `server.connected` | `restartPhaseA` + `privatePeerStatus` |
| Worker restart | `SIGTERM` exact `-pid` via `ServerManager.killProcess`, new `pid/port/epoch` strictly greater, private re-negotiates `kilo-private/1`, durable title persists | `restartPhaseB` + `privatePeerStatus` + snapshot wait |
| Title persistence | backend snapshot title equals `gcTitle` after each boundary | `snapshotClient.waitFor` |
