# Kilo GitHub Action (Retired)

The standalone Kilo CLI and this GitHub Action are retired and no longer supported.
Any workflow referencing `Kilo-Org/kilocode/github@latest` will now fail with an
error pointing here.

The supported product is the [Kilo VS Code extension](https://github.com/Kilo-Org/kilocode).

## Support

If you encounter issues or have feedback, please create an issue at https://github.com/Kilo-Org/kilocode/issues.
